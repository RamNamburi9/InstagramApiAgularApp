# Instagram API Angular Demo

Archived Angular 7 learning project that demonstrated the legacy Instagram API and implicit OAuth flow.

## Important

- The API version and authentication pattern used by this project are retired.
- The repository contains placeholders only; no application ID or personal redirect domain is committed.
- Do not use this implementation as a current authentication example.

## Historical setup

```bash
npm install
ng serve
```

This repository is retained for portfolio history rather than active use.
